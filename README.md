## 🚀 How to Run

This repository is a **Cargo Workspace**. You can run specific assignments using the `-p` (package) flag.

### Prerequisites

- [Rust & Cargo](https://www.rust-lang.org/tools/install) installed.

### Running an Assignment

To run the Library Management System:

```bash
cargo run -p book_management
```
